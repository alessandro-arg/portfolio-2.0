Ich wollte schon länger ein eigenes Homelab aufbauen. Nicht nur Sachen kaufen und hinstellen, sondern wirklich damit arbeiten.

Mein Ziel ist, Linux besser zu verstehen und mich Schritt für Schritt in Themen wie Container, Cloud und später Kubernetes einzuarbeiten.

Dafür habe ich jetzt meinen ersten Raspberry Pi gekauft, Ubuntu Server installiert und bewusst entschieden: keine GUI. Ich möchte ausschließlich nur die CLI benutzen!

## Was ich gemacht habe

Mein Setup:

- Raspberry Pi 4 Model B mit 4 GB RAM
- 32 GB microSD Karte
- per LAN verbunden
- Laptop-Netzteil mit 5V / 3A / 15W

Die SD-Karte ist erstmal nur zum Starten da. Bald werde ich auf NVMe wechseln...

Als Betriebssystem habe ich Ubuntu Server genommen. Ich habe gelesen, dass es gut für den Einstieg ist: weit verbreitet, gute Doku und ohne unnötige Oberfläche. Passt!

Installiert habe ich das OS mit dem Raspberry Pi Imager, dann die SD-Karte eingesetzt und direkt gebootet.
Ich habe auch zum ersten mal ein micro-HDMI benutzt. Etwas kleiner als gedacht.

Installation lief sauber, Netzwerk hat sofort funktioniert und der Pi ist direkt gestartet.
Danach kamen die ersten Basics im Terminal:

```bash
ssh user@raspberrypi
pwd
ls -la
sudo apt update
sudo apt upgrade
ip a
```

Klar, nichts Besonderes, aber ein Linux-System direkt über den Terminal zu benutzen ermöglicht es mir also, eine Shell zu nutzen, um Befehle an den Kernel zu senden. Finde ich cool.

## Was ich gelernt habe

### CLI wirkt erst trocken, ist aber direkt.

Am Anfang sieht das Terminal unspektakulär aus. Sobald man aber Befehle selbst benutzt, merkt man schnell, wie direkt man mit dem System arbeitet.

### Linux fühlt sich anders an als Desktop-Nutzung.

Man klickt sich nicht einfach durch das Menu, sondern muss verstehen, was man tut. Genau das finde ich interessant. Ich nutze Windows seit zehn Jahren, und vermisse es nicht. Man ist unabhängiger, wird nicht mit App-Empfehlungen genervt, muss keinen Account erstellen und vor allem gibt es keine Telemetrie. Geil.

### Hardware wird plötzlich relevant.

Netzteil, Speicher, LAN , Boot-Medium. Dinge, über die ich am normalen Rechner kaum nachdenke, spielen hier direkt eine Rolle.

### Anfangen ist wichtiger als perfekt planen.

Ich habe noch keinen Container deployed und keinen Cluster gebaut, ABER ich habe angefangen! Ich werde mich jetzt für ne weile auf Linux und Bash konzentrieren. Wenn ich das verinnerlicht habe, fängt der Spaß erst an!

Ich habe jetzt ein eigenes kleines System, auf dem ich Dinge testen, kaputtmachen und wieder reparieren kann. Genau so lerne ich am besten.
