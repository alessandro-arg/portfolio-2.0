I had wanted to build my own homelab for a while. Not just buying things and putting them somewhere, but really working with them. I have been using Windows for ten years, and I don’t miss it. But at the same time, I realized I’ve only ever known that one environment. Now I want to explore other systems, other ways of working and other perspectives.

My goal is to better understand Linux and gradually work my way into topics like containers, cloud and later Kubernetes.

I decided to use a Raspberry Pi, installed Ubuntu Server and consciously decided: no GUI.
I want to use only the CLI.

### My setup

- Raspberry Pi 4 Model B with 4 GB RAM
- 32 GB microSD Karte
- connected via LAN
- laptop power supply with 5V / 3A / 15W

The microSD card is only temporary. I will soon switch to more storage and a NVMe.

As operating system I chose <Hl>Ubuntu Server 24.04 LTS</Hl>. I read that it is good for getting started: widely used, good documentation and without unnecessary interface. Nice!

## What I did

I installed the OS with the Raspberry Pi Imager, then inserted the SD card and booted directly.
I also used a micro-HDMI for the first time. A bit smaller than expected.

Installation went smoothly, network worked immediately and the Pi started right away.
After that came the first basics commands in the terminal:

- <Hl>whoami</Hl> → prints username
- <Hl>hostname</Hl> → prints the name of the connected computer
- <Hl>pwd</Hl> → 'print working directory', shows current location in the file
  system
- <Hl>ls</Hl> → shows files and folders in the current directory
- <Hl>date</Hl> → prints current date and time
- <Hl>echo</Hl> → print text to the terminal
- <Hl>cat</Hl> → display the contents of a file
- <Hl>uptime</Hl> → show how long the system has been running
- <Hl>touch</Hl> → create an empty file
- <Hl>rm</Hl> → remove a file, no confirmation, no trash bin
- <Hl>history</Hl> → show all commands you've run
- <Hl>which</Hl> → show the location of a command

Sure, nothing special, but i understood that using a Linux system directly through the terminal allows me to use a shell to send commands to the kernel. It’s cool.

## What I learned

### CLI feels dry at first, but is direct.

At the beginning the terminal looks unspectacular. But once you use commands yourself, you quickly notice how directly you work with the system.

### Linux feels different than normal desktop usage.

You don’t just click through menus, you have to understand what you are doing. That’s exactly what I find interesting. This is a pretty drastic change: from a desktop experience on Windows to a pure CLI-based workflow on Linux. But I actually like it.<br/>
It feels more direct and somehow more "real".

You are more independent, not annoyed by app recommendations, don’t have to create an account and above all there is no telemetry. Just you and your hardware.

### Starting is more important than planning perfectly.

I have not deployed any container yet and built no cluster, BUT I started!

I also decided for myself that I will use AI only for research and explanations. I don’t want shortcuts when it comes to actually doing things. I want to understand what’s happening, even if it takes longer.

This is something I want to commit to. If I go down this path, I want to do it the hard way.

I will now focus on <Hl>Linux</Hl> and <Hl>Bash</Hl>for a while. Once I internalize that, the fun really begins!
